MUSTACODE - Build 1
===================
Open index.html in a browser (Chrome / Edge / Firefox). No install, no accounts, nothing is saved.
Files: index.html (page shell) + style.css (all styling) + app.js (all logic).
Fonts load from Google Fonts when online; the site falls back to system fonts offline.

Party mode (Build 1): there is no server, so the teacher and students must use TABS OF THE SAME BROWSER.
  1. Tab 1: Party Mode > Create party > "+ Add 5 demo students" (optional) > Start.
  2. Tab 2: Party Mode > Join party > enter the 6-digit code + a name.
For real multi-device classes, swap Net.init / Net.send in app.js for a WebSocket or Firebase channel.
